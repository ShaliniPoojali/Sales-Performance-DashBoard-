# Sales-Performance-DashBoard-
Developed an interactive Sales Performance Analysis Dashboard using Power BI to analyze sales, profit, targets, returns, and regional performance. The dashboard presents business insights through KPI cards, charts, and interactive filters.
# Project Objective
The objective of the Sales Performance Analysis Dashboard is to analyze sales data and monitor key performance indicators, including total sales, sales targets, profit, and returns. The dashboard helps track monthly sales trends, compare sales performance across regions and product categories, and evaluate regional manager performance to support data-driven decision-making.
# Tools Used
Microsoft Excel – Used for data cleaning and data preparation.
Microsoft Power BI – Used to create interactive dashboards, visualize sales data, and track key performance indicators (KPIs).
# Dashboard Features
KPI Cards: Display Total Sales (18M), Total Targets (19M), Total Profit (2.96M), and Total Returns (804).
Monthly Sales Analysis: Tracks sales trends over time.
Sales vs. Target Analysis: Compares actual sales with sales targets.
Regional Performance: Analyzes sales across different regions.
Category-wise Analysis: Shows sales performance across product categories.
Regional Manager Analysis: Compares sales performance by regional manager.
Interactive Slicers: Filter data by date, region, regional manager, and category.
Data Visualization: Presents sales insights through charts, graphs, and KPI cards.
Delivery and Returns Analysis: Helps monitor delivery days and product returns.
# Conclusion
The Sales Performance Dashboard provides insights into sales, targets, profit, and returns. It helps analyze sales trends and regional performance to support better business decisions.
